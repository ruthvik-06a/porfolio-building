# Line Editor - Help

## About

This is a simple command-line line editor written in C.

The editor allows the user to:
- Insert a line
- Delete a line
- Display the document
- Exit the program

---

## 1. Insert Line

Adds a new line at the specified line number.

### How to use

Choose:

    1. Insert line

Then enter the line number and the text.

### Example

    Enter your choice: 1
    Enter line number (1 to 1): 1
    Enter text: Hello World

Output:

    Line inserted successfully!

---

## 2. Delete Line

Deletes a line from the document.

### How to use

Choose:

    2. Delete line

Then enter the line number you want to delete.

### Example

    Enter your choice: 2
    Enter line number to delete (1 to 3): 2

Output:

    Line deleted successfully!

---

## 3. Display Document

Displays all current lines with their line numbers.

### How to use

Choose:

    3. Display document

### Example

    Enter your choice: 3

Output:

    ----- DOCUMENT -----
    1: Hello World
    2: I am learning C
    3: This is my line editor
    --------------------

---

## 4. Exit

Exits the Line Editor.

### How to use

Choose:

    4. Exit

### Example

    Enter your choice: 4

Output:

    Exiting Line Editor...
